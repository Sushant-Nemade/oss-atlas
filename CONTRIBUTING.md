# Contributing

Thanks for helping improve OSS Atlas!

1. Search existing issues and PRs. For substantial changes, open an issue first.
2. Use Node.js 20+, run `npm install`, then `npm run dev`.
3. Keep TypeScript types explicit and changes focused.
4. Add tests for scoring and analysis behavior.
5. Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`.
6. Include screenshots for meaningful UI changes.
7. Avoid analytics, tracking, or client-side secrets.

Scoring changes must be documented and tested. Contributions are distributed under the MIT license.
